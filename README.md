# Contact Form Web Application

A simple full-stack contact form built using HTML, CSS, JavaScript, and Node.js.

This project allows users to submit their contact details which are stored in a text file through a backend server.

## Technologies Used
- HTML
- CSS
- JavaScript
- Node.js

## Features
- Simple and clean UI
- Backend server handling form submissions
- Data stored in file

## How to Run
1. Install dependencies  
   npm install  

2. Start server  
   node server.js  

3. Open in browser  
   http://localhost:3000/index.html  

## Learning Outcome
- Frontend and backend connection
- Basic Node.js server
- Handling form data
